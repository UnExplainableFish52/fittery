# Cyberpunk charging dashboard - Build 17

Current asset: `assets/charging/cyberpunk_bay_v1.webp` (1024 x 1536, 43,352 bytes). Generated using the built-in image tool; encoded to WebP at quality 84. The earlier aurora asset is retained for reference in the repository but is not bundled in this build.

## Direction and composition

The background is original artwork. No reference image is used as an app asset or as a generation input. The [HUD Dashboard Interface study](https://www.behance.net/gallery/163356309/HUD-Dashboard-Interface) informed the use of quiet instrument areas and fine geometric framing. [Cyberpunk Style - Complete Dashboard + Mobile](https://dribbble.com/shots/27064373-Cyberpunk-Style-Complete-Dashboard-Mobile) was also researched for dark/violet palette direction. These are inspiration sources, not designs to reproduce.

The palette combines near-black ink, cyan, teal, soft violet and a small amber accent. Strong bitmap structure stays at the perimeter. Flutter draws the actual gauge, percentage, source, metric cards, and dismiss control; the generated image contains no text, measurements, gauges, or controls. Bevelled card frames, etched corners and gauge marks use the widgets' own coordinates, allowing correct alignment in portrait, landscape and large-text layouts. Measurements use tabular monospace numerals.

The abstract perimeter artwork stretches to the viewport so tall phones retain the illuminated side rails. It contains no figures, printed frames or measurements whose proportions need preserving. The background is decoded at a capped width and remains inside a repaint boundary. Gauge framing and panel detail are static. Only the existing small charging trail animates; no new sensor subscription, timer, animation controller, animated shader effect or permission is introduced.

## Final generation prompt

> Use case: stylized-concept. Asset type: ORIGINAL production background artwork for a premium cyberpunk Android charging dashboard, portrait 1024 x 1536. Create an understated futuristic power-instrument bay, near-black charcoal and midnight ink with subtly machined ceramic-metal materials. This is a quiet, precisely art-directed UI backdrop, NOT a screenshot or mockup. At the extreme left and right edges, layered thin beveled armor seams, occasional inset cyan luminous traces, restrained indigo-violet spill at the upper right and a very small warm amber reflection at the lower left. The lighting is sophisticated and cinematic but controlled, almost all pixels dark; crisp technical diagonals and clipped corners rather than flowing silk or smoke. Composition is deliberately built for our live layout: top 0-10 percent stays dark for the header; middle upper region (x 18-82 percent, y 12-59 percent) is an entirely unobstructed very dark empty instrument bay for our live percentage gauge; lower middle region (x 8-92 percent, y 62-87 percent) remains flat, dark and clean for our four live measurement cards; bottom 88-100 percent stays subdued for a dismiss slider. Keep all strong structural detail confined to the outer 10 percent edges and subtle peripheral corners so responsive layouts work without baked-in widget positions. Fine industrial material detail, elegant thin edge reflections, enough black negative space for excellent white text contrast, premium modern cyberpunk energy rather than a busy gaming HUD. ABSOLUTELY NO letters, numbers, text, logos, branding, watermark, battery symbols, icons, gauges, rings, circles, data graphs, fake readings, buttons, cards, or printed UI frames. Do not depict a phone. Do not reproduce any existing artwork or fictional game's interface. This is new original artwork using general cyberpunk principles. We will add all aligned frames, live numbers and animation in Flutter.
