## Patch behavior

- An active battery alarm adds **Silence** to the ongoing monitoring notification, before **Stop monitoring**, with a **Battery alarm active** subtitle. The dedicated temperature notification retains its Silence action. Android may require expanding the notification to reveal actions.
- Both notification actions use the same explicit, immutable broadcast PendingIntent. Acknowledging the warning stops active alarm audio, cancels alert notifications, keeps monitoring enabled, and immediately refreshes the monitoring notification and app state.
- Alarm state transitions bypass the UI telemetry throttle and notification refresh interval, so the Silence action appears promptly even when battery level and charging status stay unchanged.
- Acknowledgment preserves the existing threshold latch, preventing repeated alarms while the phone remains hot. The default remains **38 degrees C**. Existing recovery behavior is unchanged: temperature must fall strictly below the threshold minus two degrees before a later crossing can trigger a new warning (below 36, then back to 38 for the default).

The dedicated temperature notification also supports Silence. Restore the preferred threshold afterward. Do not deliberately heat the phone for this check.
