# Fittery v1.2.1 (Build 28)

Fittery v1.2.1 improves battery alerts, notification customization, and first-time setup.

## What's new

- **Custom notification elements:** Show all metrics, or choose up to three from Current, Power, Temperature, and Time remaining in the live monitor notification.
- **In-app battery alerts:** Charging-target, low-battery, and high-temperature alerts now appear in the app with clear acknowledgement actions.
- **Improved notification setup:** Clearer permission prompts and a shortcut to Android settings help you enable notifications when needed. Saving thresholds and display preferences does not require notification permission.
- **Simpler onboarding:** First-time setup offers Background Alerts independently of live battery recording.

## Fixes and improvements

- Acknowledge individual alerts without silencing other active warnings.
- Improved temperature-alert snoozing and reminder handling.
- Improved charge and low-battery alert rearming when battery levels return across their thresholds.
- Dismissing an in-app alert preserves the screen you were viewing.
- Avoid unnecessary monitor reminders when Background Alerts is already running.
- Clearer Settings descriptions explain the difference between Background Alerts and Monitor battery.

## Installation

Download the release APK and open it on an Android 7.0 or newer device. If prompted, allow installation from the browser or file manager used to open it.

The built APK is named `app-release.apk`; the recommended GitHub asset name is `Fittery-1.2.1-build28.apk`. GitHub's automatically generated source archives contain source code, not an installable app.

An in-place update preserves app data when the package and signing certificates match. A GitHub APK may not replace a Google Play installation signed with a different Play App Signing certificate. Uninstalling removes local settings and recordings.

Allow notifications to receive battery warnings. Enable Background Alerts for warnings while Fittery is closed, and enable Monitor battery when you want live recording and updating notification readings.

Android and manufacturer battery restrictions may affect background alert delivery.
